# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Its full text applies to every project space: issues, pull
requests, discussions and reviews.

In short: be respectful and constructive, assume good faith, critique code and ideas
rather than people, and do not harass anyone.

## Reporting

Report unacceptable behaviour privately to the maintainer through the contact options
on the maintainer's GitHub profile ([@youssefbenyoussefyby](https://github.com/youssefbenyoussefyby)).
Reports are handled confidentially. The maintainer may remove content, or block
participants, that violate this code.
